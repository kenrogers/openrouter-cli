## openrouter video-generation get-video-content

Download generated video content

### Synopsis

Streams the generated video content from the upstream provider

This operation returns binary data. Use --output-file <path> to save to a file, or pipe the output to another command.

```
openrouter video-generation get-video-content [flags]
```

### Examples

```
  openrouter video-generation get-video-content --job-id job-abc123
```
